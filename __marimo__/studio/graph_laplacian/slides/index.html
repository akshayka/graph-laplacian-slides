The problem

k-means can't see shape

k-means assigns each point to its nearest centroid. That works when clusters are round blobs.

These datasets are shapes — interlocking moons, concentric rings. The nearest centroid is often in the other cluster, so the partition cuts straight through both of them.

Switch the dataset up top — the failure follows.

The matrix

Write the graph down

D — the degree matrix. Diagonal: Dii counts the edges at node i.

A — the adjacency matrix. Aij = 1 exactly when i and j are connected.

Give every node a number xi. The quadratic form adds up the squared disagreement across each edge, so vectors that are smooth on the graph score low.

The eigenvector

The low end of the spectrum knows the split

An eigenvector with a small eigenvalue barely disagrees across edges, so its entries are nearly constant on each tightly connected region.

Here the entries settle at two levels — one per cluster. Sorted by node index, the split is unmistakable. This is the Fiedler eigenvector.

The result

Cluster the eigenvector, not the points

Takeaways

What the Laplacian bought us

  1. A graph made the shape explicit. Nearest-neighbor edges encode the geometry that raw coordinates hide from k-means.
  2. The spectrum read the graph. Low eigenvectors of L = D − A are smooth across edges, so they are nearly constant on clusters.
  3. The hard problem became easy. k-means works fine — once it runs in the eigenvector's coordinates.
